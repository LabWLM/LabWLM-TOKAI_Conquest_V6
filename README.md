# TOKAI Conquest Public Source Snapshots

## English

This orphan branch reconstructs the source pairs published in the manual TOKAI Conquest GitHub Release ZIPs. It is a public Release snapshot history, not the original development history, and it does not reproduce private development commits.

This commit records the source pair published for v2.4.0. For installation, use the manual ZIP on the [v2.4.0 Release page](https://github.com/LabWLM/LabWLM-TOKAI_Conquest_V6/releases/tag/v2.4.0); do not install from this branch. The Release package provides the versioned filenames and any other files required by that release.

The two files under `src/` retain the exact published bytes. `VERSIONS.md` records their original filenames, sizes, SHA-256 values, Build ID, publication date, and public URLs.
