# TOKAI Conquest

This repository is the official release index for TOKAI Conquest.

## Installation packages

Use the single manually uploaded ZIP shown in the Assets section of the selected GitHub Release. Read the `README.md` inside that ZIP and keep its TypeScript, Strings JSON, and MAP files matched to the same release.

GitHub automatically adds **Source code (zip)** and **Source code (tar.gz)** to every Release. Those archives contain this documentation repository for developers. They are not Battlefield Portal installation packages.

The tracked repository is intentionally documentation-only. Runtime TypeScript, Strings JSON, Godot scenes, and Portal spatial files are distributed only inside the manually uploaded Release ZIPs.
