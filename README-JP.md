# TOKAI Conquest

このリポジトリは、TOKAI Conquestの公式リリース案内です。

## 導入用パッケージ

使用するGitHub ReleaseのAssets欄から、手動でアップロードされたZIPを1件だけダウンロードしてください。ZIP内の `README.md` を読み、TypeScript、Strings JSON、MAPファイルは同じリリースの組み合わせで使用してください。

GitHubが各Releaseへ自動追加する **Source code (zip)** と **Source code (tar.gz)** は、開発者向けの文書リポジトリ全体です。Battlefield Portalの導入用パッケージではありません。

このリポジトリで管理するファイルは、案内文書とライセンスだけです。実行用TypeScript、Strings JSON、Godot編集用シーン、Portalアップロード用ファイルは、手動アップロードされたRelease ZIP内だけで配布します。
